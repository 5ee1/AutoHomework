Homework Page Filler 使用说明

一、配置 DeepSeek API
1. 打开 ai-server\api-key.txt。
2. 删除占位文字，填入自己的 DeepSeek API Key。
3. 双击 start-ai.bat，使用期间不要关闭黑色窗口。

二、安装 Edge 扩展
1. 在 Edge 地址栏打开 edge://extensions/。
2. 开启“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择本目录中的 edge-extension 文件夹。
5. 网页或扩展更新后，需要在扩展管理页点击“重新加载”。

三、使用
1. 打开支持的超星作业页面。
2. 点击扩展图标。
3. 点击“AI 分析题目”。
4. 检查答案与置信度。
5. 点击“保存并立即填写”。
6. 最终提交前自行检查。

说明：
- DeepSeek API 调用可能产生费用。
- AI 结果可能出错。
- 压缩包内不包含任何 API 密钥、账号、登录状态或作业答案。
