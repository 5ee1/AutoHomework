学习通作业 AI 辅助扩展

本扩展可提取学习通作业题目，调用 AI 分析建议答案，并将确认后的答案填写到页面。
AI 答案不保证正确，请务必在最终提交前自行检查。扩展不会自动点击提交按钮。

一、配置 API
1. 打开 ai-server\api-key.txt。
2. 删除占位文字，填入自己的 DeepSeek API Key。
3. 默认使用 DeepSeek 的 deepseek-chat 模型。
4. API 调用可能产生费用，请关注服务商计费规则。

二、启动本地服务
1. 双击 start-ai.bat。
2. 使用扩展期间不要关闭启动窗口。

三、安装 Edge 扩展
1. 在 Edge 地址栏打开 edge://extensions/。
2. 开启“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择 edge-extension 文件夹。

四、使用扩展
1. 打开支持的学习通作业页面。
2. 点击扩展图标。
3. 点击“AI 分析题目”。
4. 检查建议答案、理由和置信度。
5. 点击“填写答案”。
6. 最终提交前逐题检查。

注意：
- AI 可能生成错误答案，图片题、公式题和课程专属题目的准确率可能较低。
- 学习通页面结构更新后，部分题型可能无法识别或填写。
- 请勿将 API Key 分享给他人或上传到 GitHub。
- 发布包不包含 API Key、账号、登录状态或历史答案。
- 请遵守所在组织、课程及平台的相关规则。
